# How to cite these data

If you use `Boutin_2024_project.csv`, cite the paper and the original data source below.

## Paper

Boutin, A., Gabitov, E., Pinsard, B., Boré, A., Carrier, J., & Doyon, J. (2024). Temporal cluster-based organization of sleep spindles underlies motor memory consolidation. Proceedings of the Royal Society B: Biological Sciences, 291(2014), 20231408. https://doi.org/10.1098/rspb.2023.1408

Link: <https://doi.org/10.1098/rspb.2023.1408>

## Original data

Boutin, Arnaud, Gabitov, Ella, Pinsard, Basile, Boré, Arnaud, Carrier, Julie, & Doyon, Julien (2024). *Temporal cluster-based organisation of sleep spindles underlies motor memory consolidation* (Version 5) [Dataset]. Dryad. https://doi.org/10.5061/dryad.nk98sf7xx

Source: <https://datadryad.org/dataset/doi:10.5061/dryad.nk98sf7xx>

Source table used: `Dataset_SpindleClustering__NREM2.csv`.

Original file/worksheet: `doi_10_5061_dryad_nk98sf7xx__v20240102/Dataset_SpindleClustering.xlsx | worksheet NREM2`.

## Teaching version

This folder contains a classroom subset or summary of the original data. The README describes the selection, aggregation, transformations and missing-value handling. The teaching CSV is not the complete original study dataset. No paper PDFs, raw sequencing files or instructor solutions are included.
