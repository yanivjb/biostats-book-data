# How to cite these data

If you use `De_Petrillo_2022_project.csv`, cite the paper and the original data source below.

## Paper

De Petrillo, F., Nair, P., Cantwell, A., & Rosati, A. G. (2022). The Evolution of Cognitive Control in Lemurs. Psychological Science, 33(9), 1408-1422. https://doi.org/10.1177/09567976221082938

Link: <https://doi.org/10.1177/09567976221082938>

## Original data

Rosati, Alexandra, De Petrillo, Francesca, Nair, Parvathy, & Cantwell, Averill (2024). *Data from: The evolution of cognitive control in lemurs* (Version 5) [Dataset]. Dryad. https://doi.org/10.5061/dryad.6hdr7sr2k

Source: <https://datadryad.org/dataset/doi:10.5061/dryad.6hdr7sr2k>

Source table used: `7_DePetrillo_etal_Task-Interrelations__data.csv`.

Original file/worksheet: `doi_10_5061_dryad_6hdr7sr2k__v20220726/7_DePetrillo_etal_Task-Interrelations.xlsx | worksheet data`.

## Teaching version

This folder contains a classroom subset or summary of the original data. The README describes the selection, aggregation, transformations and missing-value handling. The teaching CSV is not the complete original study dataset. No paper PDFs, raw sequencing files or instructor solutions are included.
