## Collection and row meaning

Researchers monitored two colonies of Carollia perspicillata in Brazil’s União Biological Reserve from 2013–2021, changing the focal roost in 2015. Bats were captured in roosts and with mist nets, marked individually, measured, and released. Sampling occurred roughly every two months, with gaps and unequal seasonal coverage. Advanced-pregnancy records were excluded, and weighing after feeding had ceased reduced differences in gut contents. The file contains 4,138 captures of 1,962 marked bats; ID follows the same bat across recaptures.

## Column definitions and source documentation

Data and R scripts used in Mellado et al. (2024) Not all size measures are created equal: different body size proxies are not equivalent fitness predictors in the bat Carollia perspicillata. Journal of Mammalian Evolution. 31:9. https://doi.org/10.1007/s10914-024-09702-x

bmass.txt = data set with 4138 observations (bats captured). Variables are: ID = individual number, YearMon (Year and month), Month, Sex, AgeCat = age categories (JV juvenile, SUB - subadult, AD - adult), ForL = forearm length (mm), BM = body mass (g)
