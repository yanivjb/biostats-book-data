# How to cite these data

If you use `Broome_2023_project.csv`, cite the paper and the original data source below.

## Paper

Broome, H. A. O., Woods-Lee, G. R. T., Flanagan, J., Biourge, V., & German, A. J. (2023). Weight loss outcomes are generally worse for dogs and cats with class II obesity, defined as > 40% overweight. Scientific Reports, 13(1), 22958. https://doi.org/10.1038/s41598-023-50197-y

Link: <https://doi.org/10.1038/s41598-023-50197-y>

## Original data

The authors’ source repository or supplementary data associated with the paper:

Source: <https://doi.org/10.1038/s41598-023-50197-y>

Source table used: `41598_2023_50197_MOESM1_ESM__cat.csv`.

Original file/worksheet: `41598_2023_50197_MOESM1_ESM.xlsx | worksheet cat`.
