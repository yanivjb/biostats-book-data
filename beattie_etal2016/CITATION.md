# How to cite these data

If you use `Beattie_2016_project.csv`, cite the paper and the original data source below.

## Paper

Beattie, L., Walsh, D., McLaren, J., Biello, S. M., & White, D. (2016). Perceptual impairment in face identification with poor sleep. Royal Society Open Science, 3(10), 160321. https://doi.org/10.1098/rsos.160321

Link: <https://doi.org/10.1098/rsos.160321>

## Original data

Beattie, Louise, Walsh, Darragh, McLaren, Jessica, Biello, Stephany M., & White, David (2016). *Data from: Perceptual impairment in face identification with poor sleep* (Version 1) [Dataset]. Dryad. https://doi.org/10.5061/dryad.r620r

Source: <https://datadryad.org/dataset/doi:10.5061/dryad.r620r>

Source table used: `S2_exp2data__Sheet1.csv`.

Original file/worksheet: `doi_10_5061_dryad_r620r__v20160907/S2_exp2data.xlsx | worksheet Sheet1`.

## Teaching version

This folder contains a classroom subset or summary of the original data. The README describes the selection, aggregation, transformations and missing-value handling. The teaching CSV is not the complete original study dataset. No paper PDFs, raw sequencing files or instructor solutions are included.
