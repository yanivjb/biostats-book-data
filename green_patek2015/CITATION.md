# How to cite these data

If you use `Green_2015_project.csv`, cite the paper and the original data source below.

## Paper

Green, P. A., & Patek, S. N. (2015). Contests with deadly weapons: telson sparring in mantis shrimp (Stomatopoda). Biology Letters, 11(9), 20150558. https://doi.org/10.1098/rsbl.2015.0558

Link: <https://doi.org/10.1098/rsbl.2015.0558>

## Original data

Green, Patrick A., & Patek, Sheila N. (2015). *Data from: Contests with deadly weapons: telson sparring in mantis shrimp (Stomatopoda)* (Version 1) [Dataset]. Dryad. https://doi.org/10.5061/dryad.pd256

Source: <https://datadryad.org/dataset/doi:10.5061/dryad.pd256>

Source table used: `Green_Patek_SuppData_MorphForce.csv`.

Original file/worksheet: `doi_10_5061_dryad_pd256__v20150827/Green&Patek_SuppData_MorphForce.csv`.

## Teaching version

This folder contains a classroom subset or summary of the original data. The README describes the selection, aggregation, transformations and missing-value handling. The teaching CSV is not the complete original study dataset. No paper PDFs, raw sequencing files or instructor solutions are included.
