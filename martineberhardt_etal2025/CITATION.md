# How to cite these data

If you use `Martin-Eberhardt_2025_project.csv`, cite the paper and the original data source below.

## Paper

Martin-Eberhardt, S. A., Weber, M. G., & Gilbert, K. J. (2025). Anthocyanin Impacts Multiple Plant-Insect Interactions in a Carnivorous Plant. The American Naturalist, 205(5), 502-515. https://doi.org/10.1086/735010

Link: <https://doi.org/10.1086/735010>

## Original data

Martin-Eberhardt, Sylvie, Weber, Marjorie, & Gilbert, Kadeem (2025). *Anthocyanin impacts multiple plant-insect interactions in a carnivorous plant* (Version 8) [Dataset]. Dryad. https://doi.org/10.5061/dryad.8w9ghx3vp

Source: <https://datadryad.org/dataset/doi:10.5061/dryad.8w9ghx3vp>

Source table used: `CombinedDataset.csv`.

Original file/worksheet: `doi_10_5061_dryad_8w9ghx3vp__v20250103/CombinedDataset.csv`.

## Teaching version

This folder contains a classroom subset or summary of the original data. The README describes the selection, aggregation, transformations and missing-value handling. The teaching CSV is not the complete original study dataset. No paper PDFs, raw sequencing files or instructor solutions are included.
